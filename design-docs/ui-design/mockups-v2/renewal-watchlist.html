Two things this list deliberately does not do. It does not create the renewal order — a person does that in Orders (D-1), so there is no action button here beyond Open. And the increase column is what the paper says; Orders will renew at then-current product pricing unless someone applies it. That gap is the point of the column.

Quick tabs vs. Filter. The pills are the four questions finance asks daily and should stay one click; Filter is everything else, driven in-session. Saved views are deliberately out — persisting custom watchlists is phase 2 or never (D-21). This screen is the stock MJ grid over the layered base view plus this chrome, and the grid selects the base view so customers and types render as names rather than IDs (D-23).
