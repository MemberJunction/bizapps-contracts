The "Source" column is a design proposal, not a schema field. There is no column recording whether a contract came from a deal, an auto-renewal, or a person typing it in. It can be derived — a deal-sourced contract is one sales points at, an auto-renewed term has RenewalOfTermID set with no deal — but the manual case is exactly the one with no marker at all. If this column is worth having, it wants either a Contract.OriginType or a first ContractEvent whose EventType is the origin.
