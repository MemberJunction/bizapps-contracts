A contract refused for having no template now says when no Published template with a document or URL exists, and to publish one under Templates. Statement of Work no longer requires a template (`TemplateRequired = false`), so the server default stops attaching the Master Agreement to SOWs. The README install section states that a template must be published before the first Order Form or Payment Link.
